One-letter entry for the make.fun bounty **"One Letter: Coffee or Tea"**.

`main.py` writes exactly one letter to `/output/entry.txt` — **A for coffee** — one byte, no newline, no punctuation, no explanation, as the rules require. The sealed gate checks for 1 to 1 characters, and a judge model compares the letter against other entries on vividness, humour and truth.
